개인정보 처리방침

최종 수정일 : 2026년 9월 6일

1. 개인정보 수집

본 확장 프로그램은 개인정보를 수집하지 않습니다. 이름, 이메일 주소, 위치, 검색 기록, 브라우징 기록, 기기 정보 등 어떠한 개인정보도 수집·저장·전송하지 않습니다.

2. 저장되는 정보

사용자가 직접 담은 물품 정보는 사용자 브라우저의 로컬 저장소(chrome.storage.local)에만 보관됩니다. 저장 항목은 다음과 같습니다.

  • 품명, 규격, 모델명, 물품번호
  • 단가, 수량, 단위, 할인가 적용 여부
  • 해당 상품 페이지의 주소

이 정보는 사용자의 컴퓨터를 벗어나지 않으며, 개발자를 포함한 제3자는 접근할 수 없습니다.

3. 외부 전송

본 확장 프로그램은 어떠한 외부 서버와도 통신하지 않습니다. 상품 정보는 사용자가 이미 열어 둔 페이지의 화면에서 읽으며, 별도의 요청을 보내지 않습니다. 엑셀 파일 생성 역시 전적으로 사용자의 브라우저 내에서 이루어집니다.

4. 권한 사용

사이트 접근 권한은 사용자가 ‘물품 담기’를 실행한 시점에만 사용됩니다.

  • 조달 사이트(s2b.kr, g2b.go.kr)는 기본 권한으로 포함됩니다.
  • 그 밖의 사이트는 사용자가 최초 사용 시 직접 허용한 경우에만 접근하며, 사이드패널의 설정에서 언제든 해제할 수 있습니다.

5. 정보 삭제

사이드패널의 초기화 버튼을 누르거나 확장 프로그램을 삭제하면 저장된 정보는 모두 지워집니다.

6. 처리방침 변경

본 처리방침이 변경되는 경우 이 페이지를 통해 공지합니다.

7. 문의

여기에 문의받을 이메일 주소를 적어 주세요.

본 확장 프로그램은 개인이 제작한 것이며 교육부, 한국교육학술정보원 등을 포함하여 언급된 기관과 아무런 관련이 없습니다.
